# Phase 10: PothosComms on the pothos2 core — plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The fork `markvin/PothosComms` (branch `pothos2`) builds against
an installed pothos2 core, without Poco and without spuce. All its
self-tests pass in CI on 5 jobs.

**Architecture:** comms gets the build of PothosBlocks: a top-level
`CMakeLists.txt` with `find_package`, a module helper, a staged CTest
runner. The SIMD kernels of `math` use `<Pothos/Util/XSIMDCopy.hpp>`. A new
internal static library `comms_filter_design` (`filter/design/`) replaces
spuce. Its tests compare it with reference data. A generator program
outside the build makes this data one time from spuce `ad08df7`.

**Tech Stack:** CMake ≥ 3.25, C++23 (C for `fft/kiss_fft.c`), Conan 2
(`conanfile.txt`, CMakeDeps, CMakeToolchain), nlohmann_json 3.12.0, xsimd
14.2.0 (Conan) / 14.3.0 (Arch), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-28-phase10-comms-design.md`
